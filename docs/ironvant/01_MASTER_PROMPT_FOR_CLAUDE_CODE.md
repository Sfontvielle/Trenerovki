## 1. ГЛАВНАЯ ЦЕЛЬ ПРОДУКТА

IRONVANT — премиальный, технологичный, локализованный на русский и английский языки коммерческий iPhone fitness/wellness coach для тренировок, питания, прогресса, активности и восстановления. iPhone — приоритет. Android пока не реализовывать. Рабочее название IRONVANT не означает, что бренд юридически свободен.

Главная продуктовая ценность: пользователь легко проходит онбординг, получает персональную тренировочную программу, выполняет тренировку по упражнениям и подходам, надёжно сохраняет результаты, видит динамику, при необходимости получает объяснимые предложения AI Coach и может принять, изменить или отклонить их. Питание, восстановление и Apple-экосистема дополняют этот процесс.

Премиальный стиль Neural Performance: тёмная база `#090D1C`, панели `#172238`, акценты cyan `#22D3EE` и violet `#6478FF`, дополнительные настраиваемые акценты, светлая тема, хорошая типографика, карточки, адаптивность, системные safe areas, accessibility/Reduce Motion. Пять вкладок: **Главная, Тренировки, Coach, Питание, Прогресс**; профиль — через аватар. Приветствие перед анкетой; анимация логотипа как энергетический импульс. Анимация должна быть эффектной и производительной, без снижения доступности.

## 4. ПРОДУКТОВЫЕ КОМПОНЕНТЫ — РЕАЛИЗОВАТЬ ПОЭТАПНО

### 4.1. Онбординг, профиль и Главная
- Отдельный премиальный welcome с энергией/нейронным ядром до анкеты.
- Имя обязательно, пол мужчина/женщина, возраст 18+, вес, тренировочный опыт, одна главная цель, ограничения/доступность/оборудование, ритм занятий. Персональные чувствительные поля — со справедливой возможностью пропуска, где допустимо.
- Цели: набор, сушка, рекомпозиция, сила, поддержание по применимости. Не собирать целевой вес без необходимости.
- Главная — прежде всего текущая тренировка, затем шаги, КБЖУ, масса тела, сон, восстановление и полезные действия Coach. Не показывать выдуманные значения датчиков.
- Гость может начать без аккаунта; необязательный Sign in with Apple с безопасным связыванием профилей.

### 4.2. Workout Engine — приоритет №1
- Планирование и запуск, упражнения по отдельным рабочим экранам и обзор всей сессии, наборы вес/reps/RIR/заметки, план/факт, предзаполнение из последней сессии, редактирование, повторы прошлых тренировок.
- Прогрессия и авторегуляция веса/повторов/объёма, приоритетный учёт цели, уровня, восстановления и ограничений, подтверждение предлагаемых изменений. Разминка по желанию; суперсеты/трисеты/круговые, drop sets, rest-pause; таймер отдыха необязателен.
- Формальная state machine с `Planned / Active / Paused / Completed / Cancelled`, техническим режимом recovery, уникальными `session_id`, `set_id`, `operation_id`, транзакционным журналом. Подтверждённый подход не считается сохранённым до фиксации в SQLite.
- Восстановление после сбоя, повторных нажатий, отсутствия сети. Устойчивые события для будущей синхронизации с Watch и разрешения конфликтов без скрытого удаления одной из версий.
- Правильные единицы веса, даты, часовые пояса, продолжительность с учётом пауз, история нагрузок и объёмов.

### 4.3. Exercise Library и Neural Anatomy Studio
- Экспертно проверенный каталог упражнений с фильтрами, альтернативами, пользовательскими вариантами, оборудованием, инструкциями и ссылками на научные материалы.
- Целевой ориентир **500–800 качественных упражнений**, из них **50–100 полноценных проверенных 3D-анимаций** по мере развития; не фабрикуй контент и не обещай, что весь объём войдёт в 1.0.
- Реалистичный атлетический **взрослый мужчина-бодибилдер** с анатомически правдоподобным объёмом мышц, отдельной мускулатурой, пропорциональными суставами и читаемым рельефом — не худой манекен и не абстрактная фигура. Отдельно от концептуального энергетического Coach-аватара.
- Blender, качественный rig/IK, анимации упражнений, реальные хваты/снаряды, научная/анатомическая проверка. Источники моделей/текстур/анимаций и коммерческие лицензии фиксировать до использования.
- RealityKit/Swift bridge, интерактивное вращение, масштабирование, подсветка рабочих мышц по фазам, короткий локальный клип/GIF fallback, контроль LOD/памяти/температуры и лицензии.
- **В версии 1.0 — ограниченное число действительно рабочих и проверенных сцен**, не фиктивный 3D-экран.

### 4.4. Nutrition, Recovery, HealthKit, Watch
- Дневник питания с корректными КБЖУ и порциями, ручной ввод, поиск; расширяемая архитектура barcode/photo/recipes/meal plans; проверка лицензий и источников продуктовых данных.
- Сон, шаги, активность, восстановление и readiness только по действительно доступным разрешённым данным; дедупликация HealthKit, учет пропусков и отсутствия датчиков.
- Продвинутые Apple Watch, Live Activities/Dynamic Island, голос и анализ видео могут выходить по этапам после основной 1.0 согласно решению №099. Контракты для них заложить заранее; утверждённые целевые функции не отменять.
- Video Studio и live technique: биомеханика с понятной уверенностью и ограничениями наблюдаемости, без диагноза и псевдоточных оценок.

### 4.5. AI Coach
- Гибридный local/cloud с разделением: точные числовые расчёты — локальная проверяемая логика; LLM — объяснение/формирование допустимых предложений.
- Структурированная память `Neural Context Memory`: короткий контекст, подтверждённые факты, решения и события, provenance, timestamp, устаревание, конфликт, Memory Control Center. Не сохраняй все чаты автоматически, не превращай догадки ИИ в факты.
- Adaptive Preference Learning: не приравнивать поведение к явному предпочтению; управление пользователем.
- Recommendation Guardrails и User Decision Control: предложение, проверка ограничений, объяснение, принятие/частичное изменение/отказ/отложить, повторная проверка, историчность и undo без изменения фактических завершённых результатов.
- Evidence-Governed Knowledge: научный корпус с версионностью, подтверждённые источники, DOI/PMID где есть, редакционная проверка, отслеживание опровержений/ограничений, доступный offline synopsis, запрет вымышленных цитат.
- Health & Safety: независимые hard rules, обнаружение явно сообщённых тревожных ситуаций, прекращение неподходящих тренировочных советов, рекомендация обратиться за помощью при необходимости, без медицинских диагнозов.
- Разделение моделей по сложности/цене и разрешению передачи данных; Privacy-First Observability, Quality Gates, RU+EN eval, управление экспериментами и cost caps.

### 4.6. Commerce
- **Free Core** сохраняет тренировку, историю, прогресс, базовое питание, локальные расчёты, безопасность и экспорт без оплаты.
- Постоянные Premium-функции — StoreKit 2 `Non-Consumable`; дополнительный облачный AI — пакеты `Consumable` Small/Medium/Large. **Подписка не обязательна и на старте не утверждена.** Не назначай цены без бизнес-расчёта.

- Оплаченные IAP-кредиты не истекают. Отображение локализованной цены и прозрачного предварительного расхода до подтверждения операции. Расходуемые кредиты переносятся только с восстановимой платёжной идентичностью; не обещай анонимное восстановление без идентификатора.

## 7. ОТЧЁТ ПОСЛЕ КАЖДОГО ЭТАПА

Отвечай **на русском**, технические имена кода допускаются на английском. Структура отчёта:
