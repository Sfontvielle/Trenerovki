## Известные риски

- `npm audit` на SDK 58 показывает 16 предупреждений: 13 низких и 3 высоких. Все они идут от пакетов `deepmerge` и `zod` внутри инструментов Expo и Jest. Автоисправление откатывает проект на SDK 51, поэтому не применяется. Проверять заново при обновлениях SDK.
- Решения №035–037 задают только основные цвета. Остальные значения в `src/design-system/tokens.ts` предложены разработкой и подтверждены владельцем на iPhone как общий стиль, отдельные значения можно менять.
- Нижняя панель вкладок нативная: в браузере её вид не проверяется, только на iPhone.
- Каталог упражнений, отметки сложности и нагрузки на зоны, диапазоны повторов и шаг прибавки веса составлены разработкой без экспертной проверки (№068).
- Экспорт нельзя загрузить обратно: для восстановления нужны `expo-file-system` и `expo-document-picker`.

## Частично выполнено после проверки агентами

- №004, №005: в анкете 5 блоков из 8, нет исходной формы, образа жизни и сна, питания.
- №009: нет расписания по дням недели.

- №013, №015: подсказка только по весу.
- №016: в первой тренировке значения не подставляются.
- №033: показана следующая, а не сегодняшняя тренировка.
- №034: к открытой тренировке можно вернуться с Главной и Тренировок, но не с других вкладок.
- №039: нет логотипа и знакомства с Coach, анимация ядра временная.
- №092: есть отметка дискомфорта и оговорка, зон ограничений только три.
- №096: экспорт без восстановления.
- №103: нет предварительной проверки перед миграцией и `runtimeVersion`.
