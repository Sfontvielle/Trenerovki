# Tech Risk Register

| Риск | Влияние | Что сделано | Что нужно |
|---|---|---|---|
| Нативные функции не проверены на устройстве: камера, шаги, звук, тактильный отклик | Функция может вести себя иначе на iPhone | Логика покрыта тестами, у всех есть понятное состояние отказа | Проверка на iPhone |
| Памятки, диапазоны повторов, лёгкая неделя, пороги готовности составлены без эксперта | Риск травмы или вредного совета | Подпись «специалист не проверял», правило о тревожных симптомах | Тренер, спортивный врач |
| Цели КБЖУ считаются по формуле без медицинской проверки | Неподходящий ориентир при заболеваниях | Формула названа, нижний предел, предупреждение | Врач или диетолог |
| Значения в базе продуктов составлены вручную | Ошибка в подсчёте | Метка «типовые значения», тест на соответствие калорий и БЖУ | Лицензированная база |
| Open Food Facts: лицензия ODbL, данные пользователей | Неточные данные, требования к атрибуции | Атрибуция в «О приложении», значения показываются на проверку | Проверка юристом |
| Название IRONVANT не проверено | Спор о товарном знаке | Рабочее имя | Юрист |
| `npm audit`: 46 предупреждений в инструментах сборки | В приложение не попадают, риск в разработке | Отслеживается | Проверять при обновлении SDK |
| `expo install --check` в CI зависит от выпусков Expo | CI краснеет без изменений кода | Описано в бэклоге | `npx expo install --fix` |
| База расширена семью миграциями, одна пересобирает таблицы | Потеря данных при сбое | Транзакция, проверка целостности, копия, тест на сохранность | Проверка обновления на реальных данных |
| Хранилище браузерного превью ненадёжно: база доступна одной вкладке, а после закрытия панели браузера данные пропадали | Только превью для разработки, тестовые данные могут исчезнуть | Вторая вкладка воспроизводит ошибку загрузки, с одной вкладкой данные пережили перезагрузку и перезапуск сервера. На iPhone используется обычный файл SQLite, а не это хранилище | Подтвердить сохранность на iPhone |
| Метки нагрузки на зоны расширены разработкой | План может не учесть ограничение | Текст говорит «по нашей разметке», предупреждение о боли | Тренер или физиотерапевт |
| Удаление строк из SQLite оставляет следы в свободных страницах файла | Данные могут частично сохраняться после удаления | Копии перед обновлением удаляются | Проверка специалистом по безопасности |
| Названия дней и решения Coach хранятся на языке создания | Смена языка iPhone оставит старые названия | Косметика | Хранить ключи при следующей переработке |
| Сигнал конца отдыха срабатывает, только когда приложение открыто | Свёрнутое приложение промолчит, таймер покажет время при возвращении | Отсчёт идёт по часам, поэтому не сбивается | Локальные уведомления в сборке приложения |
| Карта недавней нагрузки считается по простому правилу: подходы и три дня затухания | Может выглядеть как оценка состояния мышц | Подпись «примерная картина», это не оценка | Тренер |
| Шрифт цифр загружается при запуске | При сбое цифры будут системным шрифтом | Приложение не блокируется | Проверить на iPhone |
| В приложении нет ссылки на политику конфиденциальности | Нужна для App Store | Полный текст в разделе «О приложении» | Опубликовать текст и проверить у юриста |
