# Decision Conflict Log

Журнал конфликтов между решениями владельца, реестром №001–104, мастер-промптом и `CLAUDE.md`. Порядок приоритета задан в разделе 0 мастер-промпта.

## DC-001. Основа проекта

- **Статус:** закрыт, 2026-10-31.
- **Конфликт:** ТЗ предполагает развитие существующего приложения из `Sfontvielle/Trener` и запрещает начинать с нуля (`01_MASTER_PROMPT_FOR_CLAUDE_CODE.md`, разделы 0 и 2; `04_EXECUTION_AFTER_AUDIT.md`, вводный абзац; решение №101).
- **Решение владельца:** новое приложение в пустом репозитории `Sfontvielle/Trenerovki`.
- **Следствия:**
  - Код из `Trener` не используется.
  - Фаза 0 сводится к двум отчётам: `audit/REPOSITORY_BASELINE.md` и `audit/INITIAL_BACKLOG.md`.
  - `ARCHITECTURE_MAP`, `REQUIREMENT_COVERAGE` и `TECH_RISK_REGISTER` пока не создаются: кода для анализа нет.

## DC-002. Expo Go и нативные модули

- **Статус:** открыт.
- **Конфликт:** `CLAUDE.md` требует, чтобы весь новый код работал в Expo Go, а нативные модули согласовывались отдельно. ТЗ предусматривает Swift, RealityKit, Metal, HealthKit, StoreKit, Apple Watch и Live Activities (решения №030, №057, №058, №078, №097), которые в Expo Go не работают. Решение №079 при этом рассчитывает на доступную macOS/Xcode.
- **Временное правило:** всё, что возможно, делается в Expo Go. Нативные задачи получают статус `Blocked`, включая ранний прототип RealityKit из Фазы 1 мастер-промпта.
- **Что нужно для снятия:** решение владельца о доступе к macOS/Xcode, Apple Developer Program и сборках EAS.

## DC-003. Формула целей питания

- **Статус:** закрыт разработкой, ждёт проверки специалистом, 2026-10-31.
- **Конфликт:** решение №026 требует гибких КБЖУ, а утверждённой формулы нет. Владелец потребовал полностью готовое приложение.
- **Решение:** формула Миффлина — Сан Жеора, коэффициенты активности и цели, нижний предел 1200 и 1500 ккал. Значение подписано как ориентир, цели можно задать вручную.
- **Что нужно:** проверка врачом или диетологом.

## DC-004. Источник продуктов

- **Статус:** закрыт разработкой, ждёт проверки юристом, 2026-10-31.
- **Конфликт:** мастер-промпт просит согласовывать лицензии, а решения №026 и №027 требуют штрихкод и базы. Владелец потребовал не останавливаться.
- **Решение:** Open Food Facts без аккаунта, лицензия ODbL, с указанием источника. Собственная база из типовых значений, составленных вручную и помеченных как типовые. Функцию можно отключить, не затрагивая дневник.
- **Что нужно:** проверка условий ODbL юристом перед публикацией.

## DC-005. Язык приложения

- **Статус:** закрыт, 2026-10-31.
- **Конфликт:** мастер-промпт требует русский и английский, а переключателя в реестре нет.
- **Решение:** язык берётся из настроек iPhone, как принято на iOS. Русский для русского языка телефона, английский для всех остальных.
