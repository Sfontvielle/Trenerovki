# IRONVANT — пакет для Claude Code

**Цель:** выполнить исходный запрос владельца — передать Claude Code полное техническое задание и начать поэтапную разработку существующего iPhone-приложения.

## Состав

- `01_MASTER_PROMPT_FOR_CLAUDE_CODE.md` — основной готовый промпт; читать/отправить первым.
- `02_DECISION_REGISTER_001_104.md` — реестр **104 утверждённых** решений, обязательный вход для агента.
- `03_SETUP_CHECKLIST_AND_RUNBOOK.md` — доступы, инструменты, лицензии, оборудование и инструкция владельцу.
- `04_EXECUTION_AFTER_AUDIT.md` — следующий короткий промпт после рассмотрения технического аудита.

## Коротко: порядок

1. Распаковать и положить файлы в `docs/ironvant/` существующего репозитория.
2. Открыть Claude Code **в корне** проекта.
3. Отправить основной промпт и убедиться, что агент прочитал реестр решений.
4. Получить технический аудит без изменений приложения.
5. Утвердить этап работ, затем использовать второй промпт для запуска реальной разработки.
6. Принимать каждую завершённую вертикаль только по доказательствам тестирования.

**Важно:** этот пакет — полноценное задание и реестр, но не исходный код готового приложения и не результаты аудита. Без физического iPhone и macOS/Xcode нельзя считать нативные Apple-функции проверенными. Решения №105+ пока не согласованы.
